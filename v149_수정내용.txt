류현상 키우기 v149 · 류현상 맞고 추가
========================================

기준 버전
- ryu-hyunsang-game-v148-quiz-healthcheck-fix.zip 기반
- 기존 온라인 퀴즈 / 러미 / 쿵쿵따 / 온라인 고스톱 기능 유지

진입 방법
- 게임 하단 [대전] → [류현상 맞고]
- 상대: 후라보노 AI
- 점당 판돈: 1,000 / 5,000 / 10,000 / 50,000 / 100,000원

화투 / 화면
- 전통 48장 구성
- 플레이어 10장 / 후라보노 10장 / 바닥 8장 / 더미 20장
- 월별 48장 전용 SVG 카드 이미지 + 전용 카드 뒷면
- 상대 손패는 뒷면, 내 손패는 앞면
- 바닥패 / 먹은패 / 손패 / 더미를 실제 맞고판처럼 구역별 배치
- 광 / 열끗 / 띠 / 피 자동 분류
- 데스크톱 / 모바일 / 가로모드 반응형 카드 겹침 배열
- 먹을 패가 같은 월로 2장 있으면 직접 선택

적용한 주요 맞고 규칙
- 광: 3광 3점, 비광 포함 3광 2점, 4광 4점, 5광 15점
- 열끗: 5장부터 1점, 이후 장당 +1
- 띠: 5장부터 1점, 이후 장당 +1
- 피: 10장부터 1점, 이후 장당 +1 / 쌍피 2장 처리
- 홍단 / 청단 / 초단 각 +3점
- 고도리 +5점
- 국진(9월 열끗)은 열끗 또는 쌍피 중 유리한 쪽으로 자동 계산
- 7점부터 GO / STOP
- 3고부터 배수 증가
- 흔들기 / 폭탄 배수
- 피박 / 광박 / 멍따 / 고박
- 뻑 / 자뻑 / 쪽 / 따닥 / 싹쓸이 및 피 뺏기
- 첫 턴 뻑 보너스
- 총통 10점 즉시 승리
- 나가리 발생 시 다음 판 배수 이월

AI
- 완전 랜덤이 아니라 먹을 수 있는 패, 광/열끗/띠/피 가치, 상대 견제, 폭탄 여부를 평가해 패 선택
- GO / STOP 판단
- 흔들기 판단

본 게임 연동
- 승패 금액이 류현상 게임머니에 반영
- 승리 수익은 기존 수입 처리 로직을 이용해 기존 채무 시스템과 호환
- 패배 시 현재 보유 게임머니까지만 차감하여 맞고로 신규 채무가 생기지는 않음
- 플레이 횟수 / 승리 횟수 / 최고 승리금 저장
- 나가리 다음판 배수 저장

기존 기능 보호
- 기존 [온라인 고스톱]은 그대로 유지
- 새 [류현상 맞고]는 별도 싱글플레이 모듈(matgo.js / matgo.css)로 분리
- 기존 게임 흐름, 온라인 대전, 저장 구조를 최대한 건드리지 않도록 구성
