류현상 키우기 v155 · 노래 맞추기 + 화투 UX 개선

[대전]
- 1:1 루미큐브 대전 메뉴/클라이언트 코드/설정 파일 제거
- 류현상 노래 맞추기 추가 · 2~4인 실시간 공개방
- 업로드한 류현상 노래 가사로 HARD 문제은행 구성
- 가사 두 줄 제시 후 바로 다음 한 줄을 직접 입력
- 노래 제목은 문제 중 숨김, 제출 후 공개
- 15초 제한 · 총 10문제
- 띄어쓰기/문장부호 차이는 무시, 오타는 오답
- 정답 100점 + 남은 시간에 따른 속도 보너스 최대 150점(문제당 최대 250점)
- 2인: 1등 20,000원
- 3인: 1등 30,000원
- 4인: 1등 50,000원 / 2등 30,000원
- 상금은 본게임 게임머니로 지급

[후라보노AI 1:1 맞고]
- 손패를 한 번 누르면 위로 올라와 선택 상태 표시
- 같은 패를 다시 누를 때 실제로 냄
- 패 내기 → 더미 뒤집기 → 먹은 패 가져가기 흐름을 애니메이션으로 표시
- AI 턴도 기존보다 천천히 보이도록 진행 속도 조정

[온라인 맞고·고스톱]
- 내 패 한 번 터치 = 선택, 같은 패 두 번째 터치 = 제출
- 상대/내 패 내기, 더미 뒤집기, 먹은 패 이동을 순차 효과로 표시
- 기존 2인 맞고 / 3인 고스톱 규칙과 판돈·채무 기능 유지

[필수 DB]
- 새 기능 사용 전 SUPABASE_SONG_QUIZ_SETUP.sql을 Supabase SQL Editor에서 1회 실행
